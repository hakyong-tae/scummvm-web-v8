# Lure of the Temptress 웹판 — M0~M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ScummVM v2026.3.0을 Emscripten으로 lure 엔진만 빌드해 브라우저에서 Lure of the Temptress(영문)를 부팅하고, 엔진에 텍스트 훅을 심어 게임 내 모든 텍스트를 캔버스 좌표에 정렬된 DOM 레이어로 다시 그린다(영문 패스스루). M3(한글)과 M4(V8 통합)는 이 플랜이 끝난 뒤 별도 플랜.

**Architecture:** 엔진(GPLv3)은 `engine-patches/*.patch`로만 건드린다. 텍스트는 `Surface::writeSubstring`에서 기록되고, `Surface::copyTo`로 표면 간 이동하며, 실제 화면에 닿는 싱크 3곳(`Screen::update/updateArea`, `Surface::copyToScreen`, `Surface::centerOnScreen`)에서 화면 좌표 JSON으로 `Module.onLureText(json)`에 전달된다. 영문 글리프는 엔진이 계속 그리고(레이어 실패 시에도 게임은 정상), DOM 레이어가 그 위에 배경색 박스 + 텍스트를 얹는다. 원본 게임 zip은 무개조.

**Tech Stack:** ScummVM v2026.3.0 · emsdk 6.0.0(`~/Downloads/emsdk`) · Vite 6 + TypeScript + vitest · Neo둥근모(SIL OFL 1.1) · Node `~/.nvm/versions/node/v23.11.0/bin`

**사전 확인된 사실(플랜 작성 시점 2026-09-06):**
- `engines/lure/surface.cpp` 텍스트 출력은 전부 `Surface::writeSubstring(x, y, line, len, transparent, color, varLength)` 경유. 폰트 8×8 고정, `fontSize[]`로 가변폭.
- 화면 싱크: `screen.cpp` `Screen::update()`/`updateArea()`, `surface.cpp` `Surface::copyToScreen(x,y)`(L395)/`centerOnScreen()`(L401). `menu.cpp`의 `copyRectToScreen(_menu->data()…)`는 비트맵 메뉴바(텍스트 아님).
- 대사는 허프만 압축, `StringData::getString(stringId, dest, hotspotName, characterName, hotspotArticle, characterArticle)`(strings.cpp L180)에서 복원.
- Emscripten 백엔드: `DATA_PATH="/data"`(HTTP 지연 로딩, `fetch("/data/index.json")` **절대경로**), `HOME=/home/web_user`(IDBFS autoPersist), 설정파일은 IDBFS에 없으면 `fetch("scummvm.ini")`(페이지 상대). 링크 시 `--pre-js dists/emscripten/custom_shell-pre.js`가 `Module["arguments"]=[]`로 초기화하고 hash에서 인자 파싱 + Web MIDI 권한 요청.
- 팔레트: `Screen::getReference().getPalette().data()` 엔트리당 4바이트 RGBx(8비트).
- `lure-1.1.zip` sha256 `f3178245a1483da1168c3a11e70b65d33c389f1f5df63d4f3a356886c1890108` (5,678,861 bytes). `lure.dat`은 ScummVM 소스 `dists/engine-data/`에 포함되어 dist 타깃이 `build-emscripten/data/`로 복사.

```bash
#!/usr/bin/env bash
# Lure of the Temptress (freeware, (C) Revolution Software Ltd) — 원본 무개조 다운로드.
# 라이선스: games/lure/data/lure/LICENSE.txt (배포 시 README/LICENSE.txt 동봉 의무)

mkdir -p "$DEST"
ZIP="$DEST/lure-1.1.zip"
if [[ ! -f "$ZIP" ]]; then
  echo "downloading $URL"
  curl -fL --retry 3 -o "$ZIP" "$URL"

  echo "sha256 mismatch: $SHA_ACTUAL" >&2; exit 1
fi
rm -rf "$DEST/lure"
unzip -q "$ZIP" -d "$DEST"
test -f "$DEST/lure/Disk1.vga" && test -f "$DEST/lure/LICENSE.txt"
echo "ok: $(ls "$DEST/lure" | wc -l | tr -d ' ') files in $DEST/lure"
```

```ts
import type { BootOptions, LureTextRecord } from './types'

declare global { interface Window { Module: Record<string, unknown> } }

export function bootEngine(opts: BootOptions): Promise<void> {
  const { canvas, engineBase, args, callbacks } = opts
  const base = engineBase.replace(/\/$/, '')

  const safe = <A extends unknown[]>(fn?: (...a: A) => void) => (...a: A) => {
    try { fn?.(...a) } catch (e) { console.error('[lure-callback]', e) }
  }

  return new Promise((resolve) => {
    window.Module = {
      canvas,
      arguments: [...args],
      enableWebMIDI: false,
      httpFsBaseUrl: base,                                 // 패치 03: "/data/…" → `${base}/data/…`
      locateFile: (path: string) => `${base}/${path}`,     // scummvm.wasm 위치
      print: (t: string) => console.log(t),
      printErr: (t: string) => console.warn(t),
      setStatus: safe((t: string) => callbacks.onStatus?.(t)),
      onRuntimeInitialized: safe(() => { callbacks.onReady?.(); resolve() }),
      onLureText: safe((json: string) => {
        const recs = JSON.parse(json) as LureTextRecord[]
        callbacks.onFrameText?.(recs)
      }),
      onLureString: safe((id: number, text: string) => callbacks.onString?.(id, text)),
    }
    const s = document.createElement('script')
    s.src = `${base}/scummvm.js`
    s.async = true
    s.onerror = () => callbacks.onStatus?.('엔진 스크립트를 불러오지 못했습니다')
    document.body.appendChild(s)
  })
}
```

```cpp
/* scummvm-web-v8: see webtext.h. GPLv3, same as ScummVM. */
// emscripten.h uses libc symbols that ScummVM poisons via common/forbidden.h (same workaround as backends/platform/sdl/emscripten)
#define FORBIDDEN_SYMBOL_ALLOW_ALL
#include "lure/webtext.h"
#include "lure/surface.h"
#include "lure/screen.h"
#include "lure/palette.h"
#include "common/array.h"
#include "common/util.h"

#ifdef __EMSCRIPTEN__
#include <emscripten.h>
#endif

namespace Lure {
namespace WebText {

#ifdef __EMSCRIPTEN__

struct Rec {
	Surface *owner;      // surface the text currently lives on (nullptr = real screen)
	int x, y, w, h;
	Common::String text; // Latin-1 as produced by the engine
	int color;           // palette index
	uint8 bg;            // palette index sampled under the text before drawing
};

static Common::Array<Rec> g_recs;     // records on surfaces
static Common::Array<Rec> g_screen;   // records on the real screen (screen coordinates)
static Common::String g_lastJson;

static bool intersects(const Rec &a, int x, int y, int w, int h) {
	return !(x >= a.x + a.w || x + w <= a.x || y >= a.y + a.h || y + h <= a.y);
}

static void removeIntersecting(Common::Array<Rec> &arr, Surface *owner, int x, int y, int w, int h) {
	for (uint i = 0; i < arr.size();) {
		if (arr[i].owner == owner && intersects(arr[i], x, y, w, h))
			arr.remove_at(i);
		else
			++i;
	}
}

// A new line of text replaces an earlier record only on the same baseline (typewriter growth, status-line
// updates). Dialogs use a 7px line pitch with 8px glyphs, so neighbouring lines overlap by one pixel row and
// must NOT count as overwrites; stale records elsewhere are pruned by stillVisible() at present time.
static void removeSameLine(Common::Array<Rec> &arr, Surface *owner, int x, int y, int w) {
	for (uint i = 0; i < arr.size();) {
		const Rec &a = arr[i];
		bool sameLine = ABS(a.y - y) < 4;
		bool xOverlap = !(x >= a.x + a.w || x + w <= a.x);
		if (a.owner == owner && sameLine && xOverlap)
			arr.remove_at(i);
		else
			++i;
	}
}

void record(Surface *owner, int x, int y, const Common::String &text, int len, int color, int widthPx, uint8 bg) {
	if (len <= 0 || widthPx <= 0)
		return;
	removeSameLine(g_recs, owner, x, y, widthPx);
	Rec r;
	r.owner = owner; r.x = x; r.y = y; r.w = widthPx; r.h = 8;
	r.text = Common::String(text.c_str(), MIN<int>(len, (int)text.size()));
	r.color = color; r.bg = bg;
	g_recs.push_back(r);
}

void transfer(Surface *src, Surface *dest, int l, int t, int r, int b, int dx, int dy) {
	if (src == dest)
		return;
	Common::Array<Rec> moved;
	for (uint i = 0; i < g_recs.size(); ++i) {
		const Rec &rc = g_recs[i];
		if (rc.owner != src)
			continue;
		if (rc.x < l || rc.y < t || rc.x + rc.w - 1 > r || rc.y + rc.h - 1 > b)
			continue; // only records fully inside the copied rect travel
		Rec m = rc;
		m.owner = dest; m.x = rc.x - l + dx; m.y = rc.y - t + dy;
		moved.push_back(m);
	}
	removeIntersecting(g_recs, dest, dx, dy, r - l + 1, b - t + 1);
	for (uint i = 0; i < moved.size(); ++i)
		g_recs.push_back(moved[i]);
}

void forget(Surface *owner) {
	for (uint i = 0; i < g_recs.size();) {
		if (g_recs[i].owner == owner) g_recs.remove_at(i); else ++i;
	}
}

// Text is considered gone once fewer than 4 pixels of its colour remain in its box.
static bool stillVisible(Surface *s, const Rec &r) {
	const byte *d = s->data().data();
	int hits = 0;
	for (int yy = r.y; yy < r.y + r.h && yy < s->height(); ++yy)
		for (int xx = r.x; xx < r.x + r.w && xx < s->width(); ++xx)
			if (d[yy * s->width() + xx] == r.color && ++hits >= 4)
				return true;
	return false;
}

static void appendJsonString(Common::String &out, const Common::String &s) {
	out += '"';
	for (uint i = 0; i < s.size(); ++i) {
		uint8 c = (uint8)s[i];
		if (c == '"' || c == '\\') { out += '\\'; out += (char)c; }
		else if (c < 0x20) { out += ' '; }
		else if (c < 0x80) { out += (char)c; }
		else { out += (char)(0xC0 | (c >> 6)); out += (char)(0x80 | (c & 0x3F)); } // Latin-1 -> UTF-8
	}
	out += '"';
}

static void appendRgb(Common::String &out, uint8 idx) {
	Palette &pal = Screen::getReference().getPalette();
	if (idx >= pal.numEntries()) { out += "[0,0,0]"; return; }
	const uint8 *p = pal.data() + idx * 4;
	out += Common::String::format("[%d,%d,%d]", p[0], p[1], p[2]);
}

static void emit() {
	Common::String json = "[";
	for (uint i = 0; i < g_screen.size(); ++i) {
		const Rec &r = g_screen[i];
		if (i) json += ',';
		json += Common::String::format("{\"x\":%d,\"y\":%d,\"w\":%d,\"h\":%d,\"t\":", r.x, r.y, r.w, r.h);
		appendJsonString(json, r.text);
		json += ",\"c\":"; appendRgb(json, (uint8)r.color);
		json += ",\"b\":"; appendRgb(json, r.bg);
		json += '}';
	}
	json += ']';
	if (json == g_lastJson)
		return;
	g_lastJson = json;
	EM_ASM({ if (Module['onLureText']) Module['onLureText'](UTF8ToString($0)); }, json.c_str());
}

void present(Surface *surface, int l, int t, int r, int b, int sx, int sy) {
	for (uint i = 0; i < g_recs.size();) {
		if (g_recs[i].owner == surface && !stillVisible(surface, g_recs[i])) g_recs.remove_at(i); else ++i;
	}
	removeIntersecting(g_screen, nullptr, sx, sy, r - l + 1, b - t + 1);
	for (uint i = 0; i < g_recs.size(); ++i) {
		const Rec &rc = g_recs[i];
		if (rc.owner != surface) continue;
		if (rc.x < l || rc.y < t || rc.x + rc.w - 1 > r || rc.y + rc.h - 1 > b) continue;
		Rec m = rc;
		m.owner = nullptr; m.x = rc.x - l + sx; m.y = rc.y - t + sy;
		g_screen.push_back(m);
	}
	emit();
}

void notifyString(uint16 stringId, const char *text) {
	Common::String utf8;
	appendJsonString(utf8, Common::String(text));
	// appendJsonString wraps in quotes; strip them (cheap reuse of the Latin-1 -> UTF-8 conversion)
	Common::String bare(utf8.c_str() + 1, utf8.size() - 2);
	EM_ASM({ if (Module['onLureString']) Module['onLureString']($0, UTF8ToString($1)); }, (int)stringId, bare.c_str());
}

#else // !__EMSCRIPTEN__

void record(Surface *, int, int, const Common::String &, int, int, int, uint8) {}
void transfer(Surface *, Surface *, int, int, int, int, int, int) {}
void present(Surface *, int, int, int, int, int, int) {}
void forget(Surface *) {}
void notifyString(uint16, const char *) {}

#endif

} // namespace WebText
} // namespace Lure
```

```ts
const isRgb = (v: unknown): v is [number, number, number] =>
  Array.isArray(v) && v.length === 3 && v.every(n => Number.isInteger(n) && n >= 0 && n <= 255)

function isRecord(v: unknown): v is LureTextRecord {
  if (!v || typeof v !== 'object') return false
  const r = v as Record<string, unknown>
  return Number.isInteger(r.x) && Number.isInteger(r.y) &&
    Number.isInteger(r.w) && (r.w as number) > 0 &&
    Number.isInteger(r.h) && (r.h as number) > 0 &&
    typeof r.t === 'string' && r.t.length > 0 &&
    isRgb(r.c) && isRgb(r.b)
}

/** 엔진 JSON → 유효 레코드만. 실패해도 절대 throw 하지 않는다. */
export function parseRecords(json: string): LureTextRecord[] {
  let v: unknown
  try { v = JSON.parse(json) } catch { return [] }
  if (!Array.isArray(v)) return []
  return v.filter(isRecord)
}
```

```ts
import type { LureTextRecord } from '../engine/types'

export const recordKey = (r: LureTextRecord) => `${r.x},${r.y},${r.t}`

export interface RecordDiff { added: LureTextRecord[]; removed: LureTextRecord[]; kept: LureTextRecord[] }

export function diffRecords(prev: LureTextRecord[], next: LureTextRecord[]): RecordDiff {
  const prevMap = new Map(prev.map(r => [recordKey(r), r]))
  const nextKeys = new Set(next.map(recordKey))
  const added: LureTextRecord[] = [], kept: LureTextRecord[] = []
  for (const r of next) (prevMap.has(recordKey(r)) ? kept : added).push(r)
  const removed = prev.filter(r => !nextKeys.has(recordKey(r)))
  return { added, removed, kept }
}
```

```ts
import type { LureTextRecord } from '../engine/types'
import { toCss } from './layout'
import { diffRecords, recordKey } from './diff'

export type Translate = (rec: LureTextRecord) => string

export class TextLayer {
  private spans = new Map<string, HTMLSpanElement>()
  private current: LureTextRecord[] = []
  private enabled = true

  constructor(private root: HTMLElement, private canvas: HTMLCanvasElement, private translate: Translate = r => r.t) {
    addEventListener('resize', () => this.relayout())
  }

  setEnabled(on: boolean) { this.enabled = on; this.root.hidden = !on }

  /** 엔진이 보고한 이번 프레임의 화면 텍스트 전체 */
  render(next: LureTextRecord[]) {
    const { added, removed } = diffRecords(this.current, next)
    for (const r of removed) { this.spans.get(recordKey(r))?.remove(); this.spans.delete(recordKey(r)) }
    for (const r of added) {
      const el = document.createElement('span')
      el.textContent = this.translate(r)
      el.style.color = `rgb(${r.c.join(',')})`
      el.style.background = `rgb(${r.b.join(',')})`
      this.place(el, r)
      this.root.appendChild(el)
      this.spans.set(recordKey(r), el)
    }
    this.current = next
  }

  private place(el: HTMLSpanElement, r: LureTextRecord) {
    const box = toCss(r, this.canvas.getBoundingClientRect())
    el.style.left = `${box.left}px`
    el.style.top = `${box.top}px`
    el.style.minWidth = `${box.width}px`
    el.style.height = `${box.height}px`
    el.style.fontSize = `${box.fontPx}px`
  }

  private relayout() {
    for (const r of this.current) { const el = this.spans.get(recordKey(r)); if (el) this.place(el, r) }
  }
}
```
